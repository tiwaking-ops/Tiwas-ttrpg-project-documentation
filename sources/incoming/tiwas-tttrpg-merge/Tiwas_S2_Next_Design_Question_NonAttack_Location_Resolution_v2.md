# Tiwas S-2 Next Design Question — Non-Attack Roll Location Resolution
## Starter Brief for New Chat (v2 - Corrected)

**Purpose**: Execute investigation into how Location Index is supplied for non-attack physical resolutions (falls, environmental hazards, etc.) — the open scope gap identified in v5 synthesis §7, incorporating corrections regarding Contact Branch sourcing and warrant attribution.

**Core Question**: When a rule calls for a Tier-1 Location Index in a non-attack physical resolution with no identifiable contemporaneous triggering agent, what specific roll supplies Zero-Step, and who declares the warrant-objective?

## Key Corrections from Analysis

1. **Contact Branch Sourcing**: Zero-Step doesn't consume "any test roll" but specifically from the **Contact Branch** — the outcome branch where hazard impact is realized (e.g., Failure in avoidance-framed tests like Reflexes to dodge debris)

2. **Watt Attribution**: For hazards, the **GM as hazard author** declares/consequences for warrant (not the affected character), aligning with existing asymmetries in:
   - Named-Outcome Test (attacking player declares; defending never does)
   - S-1 winner-only (winning participant's roll sources; losing participant's never does)

3. **Scope Clarification**: Resolving source doesn't unlock today's rope-bridge case (it's State 3 due to S-4 gaps) but prevents source from becoming a second blocker once S-3/S-4/S-7 clear Unanchored categories
