Part A — Executive Summary & Governance Boundary

A.1 What this file is and is not

What it is: A single-file, advisory development-planning compilation assembled from the 25-LLM meta-analysis and the Tiwas Alpha-Playtest Corpus. It identifies which subsystems are ready, which are missing, which require adaptation mapping, and what design decisions unblock full playtesting of Beyond the Vale of Madness — GURPS.

What it is NOT: A ruling. It does not resolve, merge, or clean up any open fork. It does not promote or demote anything. It does not invent mechanics. It does not treat agreement among 25 reports as authority.

Part B — Collated System Readiness Assessment

Playtestable Now B.1 — Core Transaction (DEC-001–DEC-012)

Tiwas baseline: Canonical / Locked

25-report convergence: Universal agreement — Playtestable Now. No disagreement recorded.

"The Core is not the problem… A large proportion of the adventure's tests reduce cleanly to ordinary Tiwas Core Tests." — ChatGPT 5.6-1

Blocking significance: None for exploration checks.

Development decision needed: None at mechanism level; content = author skill mappings.

Flag

DEC-007.A forbids any Tag/Trait/Effect from modifying Overflow damage — a structural boundary preserved in B.5/B.6 designs.

Playtestable Now B.2 — 24-Attribute Matrix & Derived Stats (DEC-003/DEC-004)

Tiwas baseline: Canonical / Locked

Convergence: Universal — mapping GURPS ST/DX/IQ/HT to Tiwas' 24 attributes is content, not a system gap.

Decision: Author the GURPS→Tiwas attribute mapping table.

Playtestable Now B.3 — S-1 Universal Opposed Contest (DEC-013)

Tiwas baseline: Canonical / Locked (DEC-013); Non-canonical Ruled (DEC-031 Quality gate).

Convergence: Universal — the adventure's Stealth vs Perception 12 (#44) is a direct S-1 test case.

"The adventure contains a genuine opposed contest: Stealth vs Perception. That maps directly into S-1 without requiring a new contest engine." — ChatGPT 5.6-1

Blocking significance: Low for the stealth branch; blocker = NPC Skill value not authored (B.13).

Adaptation Required B.4 — S-2 Location Index / Zero-Step (DEC-014, 037, 039, 041, 042)

Tiwas baseline: DEC-014 Canonical / Locked; others Non-canonical Ruled.

Convergence: Universal that Zero-Step works; divergence on whether full anatomical mapping is playable (D8).

Blocking significance: Medium for combat — requires authored armor tags (B.5) and creature anatomy (B.13).

Key ruling: DEC-041 gate — only Skills at Tier 2+ trigger Location Index; base/untrained (Tier 1) never do.

Design-Stage B.5 — S-3 Effect Menu & Gating (DEC-023–DEC-030)

Tiwas baseline: All Ruled. Structure is Ruled; gated-tier contents are NOT enumerated (open tracking item).

Convergence: Universal on architecture; divergence on blocking severity (D2).

"S-3 base-tier Inflict Injury says 'HP-only' but does not specify how much HP damage is dealt." — Kimi K3

Blocking significance: Critical for Blood Man (#38) — needs grapple, darkness, fear, ongoing corrosive damage.

Design decisions needed: Damage magnitude procedure; Condition-tier contents; Position-tier contents; time/action interaction.

Design-Stage B.6 — S-4 Wound / Injury (DEC-032–042; OPEN-007)

Tiwas baseline: Ruled; OPEN-007 consequences Ruled in principle but not table-ready.

Convergence: Universal on architecture; divergence on practical readiness (D1).

"Wound consequence magnitudes… architecture locked but contents not table-ready." — Kimi K3

Blocking significance: Medium/High — the wound state is required before the Blood Man can be grappled.

Key correction: DEC-035 — wound severity derives from the S-3 gated Effect, not an accumulated count.

Design-Stage B.7 — S-5 Armor (Tags/Traits Only; DEC-058–062)

Tiwas baseline: Ruled — Tags/Traits only; no numeric soak; never modifies Overflow (DEC-007.A corollary).

Convergence: Universal on architecture; divergence on blocking (D3).

"Armor is Tags/Traits only. No numeric durability/soak pool." — Claude 5 Sonnet

Blocking significance: High for combat fidelity — Ice Troll DR 2 cold-only, Blood Man DR 1 need Tag representation.

Decisions: Author starter Armor Tag vocabulary; confirm DEC-062 Zero-Step clause.

Playtestable Now B.8 — S-6 Active Defense (DEC-044–050)

Tiwas baseline: Ruled.

Convergence: Universal on architecture (post-hoc mitigation); divergence on practical combat readiness (D4).

"S-6 architecture is complete, but which skill or attribute the defender rolls is not specified." — Kimi K3

Blocking significance: Subsystem ready / integrated combat needs B.5/B.6/B.13.

Key rules: DEC-048 Model B (never blocks application), DEC-049 (separate roll per Effect), DEC-050 (voluntary, universal eligibility incl. positive Effects).

Playtestable Now B.9 — S-7 Incapacitation / Death (DEC-052–057)

Tiwas baseline: Ruled (register-operative; source handoff draft).

Convergence: Universal — HP = 0 forces incapacitation, no roll.

"HP = 0 forced incapacitation, no roll… Readiness: Playtestable Now." — ChatGPT 5.5-high

Decisions: Confirm DEC-054 branch selection (narrative vs mechanical death); DEC-055 GM discretion over revival attempts.

Adaptation Required B.10 — S-8 Difficulty (DEC-063–066, 043, 051)

Tiwas baseline: Ruled; numeric tier values not supplied (content gap).

Convergence: Universal on architecture; divergence on practical readiness (D7).

"What remains is the actual Tiwas difficulty-grade numerical table needed to translate the adventure's explicit GURPS modifiers." — ChatGPT 5.6-1

Blocking significance: Medium (full playtest) / Low (partial, raw Skill).

Key: DEC-051 rejected the Stakes Gate; every meaningful roll is a Core Test.

Proposal (not a ruling): Trivial +10 · Easy +5 · Standard 0 · Hard −5 · Extreme −10.

Playtestable Now B.11 — S-9/S-10 Extended Tests (DEC-067–070)

Tiwas baseline: Ruled.

Convergence: Universal — not deeply required by the adventure; usable for digging/healing.

Key: Margin accumulates monotonically (DEC-067); neutral failures (DEC-068); target set by GM (DEC-070).

Adaptation Required B.12 — S-11 Rest / Healing (DEC-071–074)

Tiwas baseline: Ruled.

Convergence: Universal — healing IS an Extended Test; the adventure's immediate "restore 1d-3 HP" does not map directly.

"The GURPS 'restore 1d-3 HP / minimum 1' procedure itself should not be imported." — ChatGPT 5.6-1

Decisions: Convert to full S-11 Extended Tests, or use simplified single-roll alpha healing.

Missing Content B.13 — S-12 Creatures / NPC (DEC-076/077)

Tiwas baseline: Architecture Ruled; actual templates NOT authored.

Convergence: Universal that content is missing; divergence on type (content task vs subsystem) — D5.

"No creature stat blocks/templates… Critical blocker." — ChatGPT 5.5-high

Blocking significance: Critical — Ice Troll (#17) and Blood Man (#38) need statted monsters.

Ownership: DEC-077 — templates are Tiwa's own authoring task, not drafted by advisory models.

Type: Mechanism design (magnitude) + content (Effects) + integration.

Priority 2 Creature / NPC Content

DEC: DEC-076/077, 041. Consensus: content universally missing (D5 preserved).

Decisions: Confirm DEC-076 mode; author Ice Troll + Blood Man via DEC-041 individual templates. Ownership = Tiwa (DEC-077).

Priority 3 Equipment, Weapons, Armor Tags, Encumbrance

DEC: DEC-015 Reserved / DEC-058–062; DEC-007.A.

Priority 4 Environmental Hazards & Fatigue

DEC: DEC-037, 015, 052, 007.A.

Closing Advisory Note

This report is a dated, one-off, non-canonical advisory compilation for internal development planning by Tiwa (2026-09-02).
