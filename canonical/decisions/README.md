# Canonical Decisions

Locked (Canonical) decisions are recorded directly within `canonical/rules/tiwas-canonical-rules-and-changelog-v1.3.md` — they were not separated into individual decision-record files, since the source document already presents them as an integrated ruleset with its own internal changelog (§17).

For a normalized, cross-referenced index of every canonical decision found in the corpus — with source section and current status — see `_consolidation/decision-register.md`, section A ("Canonical decisions").

For **non-canonical** designer rulings (real decisions, but about candidate/non-canonical material — e.g., the S-2 non-attack deferral), see `_consolidation/decision-register.md` section B. Those are not duplicated here because doing so would risk implying they are Canonical, which they are not.
