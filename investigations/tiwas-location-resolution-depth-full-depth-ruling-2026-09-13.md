## 1. Item Addressed (the Section 6 open corpus tension)

Reference: `investigations/tiwas-mirror-combat-v2-session-report-opencode-handoff-2026-09-13.md`
Section 6 (recorded, not resolved).

Three-way tension:

1. **DEC-136 R2** states "Skill-Tier maps directly to Location Tier with no cap."
   Read literally, a Skill-Tier-2 actor's location resolution could be truncated to
   Location-Tier-2 depth - stopping above leaf-level nodes like Heart/Lungs/fingers -
   within the DEC-137 hierarchy.
2. **DEC-113 R2** classifies Armor Bypass as a **binary** Tier-1-vs-Tier-2 Effect (it is
   simply "the Tier-2 Effect"), not a depth that scales further with the acting
   Skill-Tier beyond that binary gate.
3. **DEC-137's** adopted Human v1 address table is flat and unlabeled - it carries no
   per-node Tier numbers, so it contains no mechanical instruction for *how* to
   truncate even if truncation were intended.

The playtest resolved Armor Bypass to the **full DEC-137 leaf** (e.g., "Heart")
whenever the DEC-113 Tier-2 classification and the DEC-041 Skill-Tier >= 2 gate both
held - recorded as a **playtest-scoped interpretive choice only, not a ruling**.

## 2. Options Presented

- **Option 1:** Confirm the full-depth reading as the operative interpretation (closes
  the tension with no rule change).
- **Option 2:** Rule that Location-Tier depth scales with acting Skill-Tier
  independently of DEC-113's binary classification, and specify how DEC-137's flat
  unlabeled table should be truncated per Skill-Tier.

## 3. Ruling

**RULED by Tiwa, 2026-09-13 (in-session with opencode / big-pickle): Option 1 adopted.**

> Confirm the full-depth reading as the operative interpretation.

Tiwa's ruling statement (verbatim, via chat): "I rule option 1 ('confirm full-depth')."

Operative interpretation:

- A **promoted, qualifying** resolution - the Tier-2-eligible Armor Bypass (the sole
  Tier-2 Effect per DEC-113 R2) when the DEC-041 Skill-Tier >= 2 gate holds - resolves
  to the **full authored DEC-137 leaf** (e.g., Heart 30-31, Lungs 32-35) via the
  deterministic Location Index -> Location Template address path (DEC-136 R1 /
  DEC-112 L-003/L-011), with **no truncation** to a Location-Tier-2 depth above leaves.
- **DEC-113 R2's binary Tier-1/Tier-2 Effect classification is unchanged.** The binary
  classification is a gate, not a sub-leaf depth limit.
- **DEC-137's flat unlabeled address table requires no truncation scheme.** The address
  saturates at the deepest authored node (DEC-137 fork (1); max numeric Tier 4).
- DEC-136 R2's `L = min(S, D)` is read on the Tier-2 Effect path as bounding resolution
  by **authored template depth** - Skill-Tier's operative role for depth is the DEC-041
  entry gate, not a sub-leaf truncator. This is the carve-out flagged to Tiwa before the
  ruling: option 1 is not literally "no rule change" against the literal min-formula
  reading; Tiwa confirmed full-depth notwithstanding.
