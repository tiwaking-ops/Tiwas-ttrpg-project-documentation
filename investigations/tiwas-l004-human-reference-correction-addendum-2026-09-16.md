# L-004 Human-Reference Correction Addendum

## 1. Purpose and Scope

DEC-137 (2026-09-13) adopted the merged A+B **Human v1** allocation, superseding the
pre-adoption Human candidate. Six of the nine creature proposals had already been
authored against the pre-adoption candidate, so their Human-comparative claims carry
stale figures. This addendum records, **per proposal and verbatim**, each stale claim
and its corrected value derived strictly from the adopted allocation
(`investigations/tiwas-human-location-template-l009-l010-adopted-2026-09-13.md`;
register row DEC-137).

**Set-size correction:** the open-questions inventory carried this item as
"affecting seven proposals"; the verified count is **six** (Dragon and Giant Spider
cite no diverging Human numerics; Giant Spider carries only a citation-convention
note — §3.6). The inventory's P2 row should be read as "six (verified 2026-09-16)."

**Why an addendum and not in-place edits:** the stored proposals are verbatim
author records; silently patching them would corrupt provenance. Per house practice
(consolidated comparison reference §4: "proposals deliberately *not* edited in
place"), corrections ride alongside. Each correction below is a **ready-made edit
candidate** for the moment Tiwa accepts any proposal "as edited."
