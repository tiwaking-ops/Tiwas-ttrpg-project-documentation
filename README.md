# Tiwas — Consolidated Project Documentation

This repository is the output of an initial documentation consolidation performed on 2026-08-29 against a single supplied source corpus (`TTTRPG-merge-v1.md`, five embedded documents). See `PROJECT_CONTEXT.md` for what the project is, and `_consolidation/consolidation-plan.md` for the full account of this consolidation run, including what still needs your review.

## Where to look

| If you want... | Go to |
|---|---|
| The current locked Tiwas ruleset | `canonical/rules/` |
| How this documentation is governed (authority, status, provenance) | `governance/` |
| What's implemented/being sequenced, and why it isn't a rules source | `roadmap/` |

## Quick orientation

- **Only `canonical/rules/` is canonical game-mechanics source.** Everything else is either non-canonical design material, implementation/process guidance, or governance-of-the-documentation-itself.
- If you're an LLM picking up this project cold, read `governance/authority.md` and `governance/status-model.md` before making any claim about what is or isn't a rule.
- Several items described in exhaustive detail in `proposals/` and `investigations/` (e.g., the S-2 attack-side invocation policy, the S-2 non-attack deferral) are **real designer rulings but not Canonical rules** — see `_consolidation/decision-register.md` for the distinction.
